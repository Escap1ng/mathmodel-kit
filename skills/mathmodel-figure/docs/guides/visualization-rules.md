# 出图可视化规范

数模竞赛/科研论文数据图表的**唯一权威规范**。样式常量与初始化代码化实现见
`code/style/plot_style.py`（色板/纹理/尺寸/保存入口的唯一定义，禁止在脚本中另行硬编码）；
各图型的现成实现见 `code/templates/` 21 个模板。示意图（流程图/路线图/架构图）不在本规范内，
用 `mathmodel-diagram` 技能。

## 强制要求

- **每道小题至少 1 张彩色图**（建议 2–3 张）；全文建议 6 张以上，保底不低于 4 张；
  同一小问有必要时可多插（多组对比、多阶段结果）。
- **图型跟随数据结构，匹配时优先高端效果**：数据适用时优先三维曲面、热力图、等高线、
  网络/关系图、平行坐标等高级图表；基础图型（折线/柱状/饼）仍是主力，
  **禁止为视觉效果强行升级图型**（如收敛曲线强改三维曲面）。
- **组合图规范**：同一主题的多量纲指标可用双轴图；**禁止把多张不相干图硬凑成组合图**——
  多子图仅限同主题关联子图（拟合+残差、多方法对比），每个子图须在正文分别解读。
- **图内文字防重叠**：图例不遮数据（`frameon=False` 或指定位置）；轴标签过长时旋转/换行；
  数据点标注自动避让（offset/bbox/adjustText）；密集数据只标关键点。
- **拟合结果必须可视化**（拟合曲线 vs 原始数据）；**误差分析必须可视化**（残差图、误差分布图）。
- **出版级质量**：分辨率 ≥300 DPI，矢量优先；密度类图（大散点/hexbin/3D曲面）可降至 200 DPI，
  线条/柱状类优先矢量 PDF（分级策略见 `plot_style.save_fig` 注释）。
- **预览与正式版同品质**：调试图一律 `savefig.dpi=300`，禁止低分辨率预览。
- **全局-局部互补**：时序结果附关键时段放大图；分配/调度结果附关键资源利用率视图。

## 现代学术配色（必须使用）

**统一原则**：seaborn deep 学术低饱和色板——蓝-橙冷暖为主轴、紫/青为辅，中低饱和、
黑白打印有层次。角色分工（常量定义在 `plot_style.py`）：

- 定性系列 `LINE_PALETTE`：学术蓝 `#4C72B0` / 绛红 `#C44E52` / 苔绿 `#55A868` / 岩石灰 `#8E9AAF`
- 强调 `COLOR_ACCENT` 绛红（中位线/误差/负向）；`COLOR_ROCK` 岩石灰（离群点/次要线）；
  `COLOR_INK` 炭墨 `#2F353B`（文字/轴线）
- 顺序色图 `SURFACE_CMAP` 学术蓝单色渐变；发散色图 `DIVERGENT_CMAP` 蓝→灰白→绛红
- **冗余编码**：折线图线型+标记冗余；柱状图柱顶数值标注——保障色盲与黑白打印可辨

**双色板分工**：多系列/多方法对比一律 `LINE_PALETTE`；单主题内部子分组（分组柱状组内、
饼图扇区）用降饱和衍生色板 `['#7F99C5', '#D38083', '#B7CAE4', '#E5BFC0']`；
两套不在同一图内混用，模板代码禁止在这两套之外硬编码颜色。

**禁用配色**：

- ❌ 纯黑 `#000000`（一律炭墨黑 `#2F353B`）
- ❌ 纯红 `#FF0000` + 纯绿 `#00FF00` 组合（色盲不友好）
- ❌ `rainbow` / `jet` 色图（感知不均匀）
- ❌ 超过 6 种高饱和色同图

**纹理编码（可选，非默认）**：基础图表不默认加斜线/圆点纹理，靠低饱和配色 + 灰阶明暗区分；
确需区分（多组年份等）用透明度或 `HATCH_SEQUENCE`（横线 `---`、竖线 `|||`），
纹理柱体 `edgecolor` 统一岩石灰、`linewidth=0.8`。

## 高级图表配色要点

- **散点/气泡**：主色 α0.6（重叠加深体现密度）；离群/关键解用赭橙 `#DD8452` + 炭墨细描边并放大；
  气泡越大色越深；叠加拟合线用绛红虚线（冷暖对比）。
- **雷达图**：填充主色 α0.2；轮廓主色 2pt 实线；对比模型绛红虚线填充 α0.1；网格极淡灰。
- **桑基图**：节点主色/绛红/苔绿实心；连线半透明 0.4–0.6 且颜色继承起始节点。
- **地图热力图**：底图极简（海岸线/省界浅灰）；数据层单色顺序系；**禁红绿配色**。
- **平行坐标**：降采样 ≤60 条/类；透明度 0.3–0.5；按类别着三色之一；图例置图外。

## 全局视觉统一（全文图表强制）

- **主色一致**：图 1 用蓝色代表"模型A"，图 5 中"模型A"必须仍是蓝色（跨图图例一致）；
- **字体**：西文/数字 Arial 或 Times New Roman、中文 SimHei（`plot_style` 自动检测回退，
  全缺字体时告警而非静默方框），图内字号 8–10pt 级；
- **去噪**：删无意义背景色/过粗边框/阴影；去上右 spine；留白是高级感的来源。

## 基础图型要点（对内置模板的约束说明）

- **折线**：轴标注物理含义+单位；仅横向浅灰细虚线网格；性能对比坐标轴从 0 起；
  主线主色 2.5pt、对比线灰/绿 1.5pt 虚线；同图曲线 ≤5 条，超限分图。→ `line-compare`
- **分组柱状**：柱宽统一、组内距 < 组间距；单色扁平无立体；Y 轴从 0 起；柱顶数值 7–8pt 深灰；
  一组彩色 ≤4 种其余灰度。→ `grouped-bar`
- **箱线**：箱体主色填充 α0.7、中位线绛红加粗；离群点单一岩石灰小实心圆；须炭墨黑；
  可叠加半透明抖动散点。→ `boxplot-jitter`
- **饼图**：≤5 类（过多改柱状）；扁平无立体细灰分割线；百分比内嵌小字；性能对比优先柱状/折线。→ `pie-modules`
- **条形**：长类别名场景；数值轴从 0 起、条端标注同柱状规范。→ `hbar-longlabel`
- **热力图黑白打印变体**：把 `DIVERGENT_CMAP` 换单色顺序系
  `sns.light_palette('#4C72B0', as_cmap=True)`，保持细灰边框。→ `heatmap-annotated` 改参

## 交付前自检

出图自检直接对照本文件"强制要求"与"基础图型要点"：图例遮没遮数据、轴从 0 没从 0、
颜色越没越界、数值标注清不清晰、跨图主色一致没有。论文成稿阶段再按主技能
`math-modeling-helper` 第 7 章自检清单中图表相关项复核。
