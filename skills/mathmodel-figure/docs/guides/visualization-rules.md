# 出图可视化规范

数模竞赛/科研论文数据图表的**唯一权威规范**。样式常量、色板与样式助手的代码实现见
`code/style/plot_style.py`（色板/字号/尺寸/保存入口的唯一定义，禁止在脚本中另行硬编码）；
各图型的现成实现见 `code/templates/` 20 个模板。本技能的简单图型统一采用
**Nature 版式**：小字无衬线、细轴线、去冗余图例、颜色只承担语义。
模板库外需要自绘新图型时，起图流程与骨架见姊妹文件
[`nature-standard.md`](nature-standard.md)（数值条文仍以本文件为准）。
示意图（流程图/路线图/架构图）不在本规范内，用 `mathmodel-diagram` 技能。

## 强制要求

- **每道小题至少 1 张彩色图**（建议 2–3 张）；全文建议 6 张以上，最低不少于 4 张；
  同一小问有必要时可多插（多组对比、多阶段结果）。
- **图型跟随数据结构，数据适合时优先选高端图型**：数据适用时优先三维曲面、热力图、等高线、
  网络/关系图、平行坐标等高级图表；基础图型（折线/柱状/环形）仍是主力，
  **禁止为视觉效果强行升级图型**（如收敛曲线强改三维曲面）。
  模板库覆盖不到的图型**按需求现绘**，不局限于 20 个模板，也不得为套模板牺牲数据语义。
- **组合图规范**：同一主题的多量纲指标可用双轴图；**禁止把多张不相干图硬凑成组合图**——
  多子图仅限同主题关联子图（拟合+残差、多方法对比），每个子图须在正文分别解读，
  且各子图回答的问题不得重复。
- **图内文字防重叠**：图例不遮数据（默认 `frameon=False`，点云密集处可垫半透明白底）；
  优先用线尾/条端**直接标注**取代图例；轴标签过长时旋转/换行；数据点标注自动避让；
  密集数据只标关键点。
- **禁止 mathtext 与中文混排**：`"问题规模 $n$（个）"` 这类写法会让中文退化为方框
  （mathtext 段不做字体回退）。要么写纯文本 `"问题规模 n（个）"`，要么整串都用公式，勿混用。
- **拟合结果必须可视化**（拟合曲线 vs 原始数据）；**误差分析必须可视化**（残差图、误差分布图）。
- **出版级质量**：分辨率 ≥300 DPI，矢量优先；密度类图（大散点/hexbin/3D曲面）可降至 200 DPI，
  线条/柱状类优先矢量 PDF（分级策略见 `plot_style.save_fig` 注释）。
- **预览与正式版同品质**：调试图一律 `savefig.dpi=300`，禁止低分辨率预览。
- **全局-局部互补**：时序结果附关键时段放大图；分配/调度结果附关键资源利用率视图。
- **出图必做渲染自检**：见文末清单，看渲染出来的图，而不是看代码跑没跑通。

## Nature 风格配色（必须使用）

**统一原则**：颜色只承担三种职责——**身份**（这是哪个方法/哪条系列）、**方向**（升还是降）、
**层级**（主证据还是支持信息）。纯装饰性用色一律禁止。常量与色板均定义在 `plot_style.py`。

| 职责 | 常量 | 值 | 用法 |
|---|---|---|---|
| 身份·主角 | `COLOR_MAIN` | `#1A6FC4` | 本文方法/主系列，**每张图的同一含义固定不变** |
| 身份·同族 | `COLOR_MAIN_LIGHT` / `COLOR_MAIN_PALE` | `#5B9BD5` / `#B4D4F0` | 主系列变体、支持信息 |
| 身份·次系列 | `ACCENT_ORANGE` / `ACCENT_PURPLE` / `ACCENT_TEAL` / `ACCENT_CORAL` / `ACCENT_LAVENDER` | `#E28E2C` / `#7B5FD6` / `#33B5A5` / `#D9544D` / `#B89BD9` | 按序取用（`identity_color(i)`），第 0 个恒为主角蓝 |
| 基准 | `COLOR_BASELINE` / `COLOR_BASELINE_DARK` | `#767676` / `#4D4D4D` | 对照/参考/均值线，**永远是灰** |
| 方向 | `COLOR_POSITIVE` / `COLOR_NEGATIVE` | `#2E9E44` / `#E53935` | **只用于有正负的变化量**（差值、增益、损失） |
| 中性 | `NEUTRAL_BG` / `NEUTRAL_LIGHT` / `NEUTRAL_MID` / `NEUTRAL_DARK` / `COLOR_INK` | `#F5F5F5` / `#D8D8D8` / `#A8A8A8` / `#606060` / `#333333` | 底色、网格、次要文字、轴线、正文与标题 |
| 层级 | `TONE_RAMP` | 主角蓝 → 中调 → 浅调 → 中性灰 | 排名/主次：深=主证据，浅=陪衬 |
| 色图 | `DIVERGENT_CMAP` / `SEQUENTIAL_CMAP` | 蓝→浅灰→珊红 / 浅→主角蓝 | 发散矩阵 / 单极数据与黑白打印变体 |

**四条不变式**（跨图、跨子图都必须成立）：

1. **同一方法同一颜色**：某方法在子图 a 是主角蓝，在 b、c、d 与另一张图里仍是主角蓝，
   不为"更醒目"而改色；
2. **基准恒为灰**：等权重、移动平均、贪心算法等一切参照对象取 `COLOR_BASELINE`；
   不得用灰色画主角、用亮色画基准；
3. **红绿保留给方向**：绿=变好/上升，红=变差/下降，且须同时给出 `↑`/`↓` 与正负号做冗余编码；
   表达"类别身份"时改用蓝/橙/紫/青，得 0.8 分的模型不是"绿色"，而是"主角蓝"；
4. **饱和与明度编码层级**：主结果用全饱和，支持信息降饱和或走 `TONE_RAMP`；
   系列超过 6 个色相时，先考虑是否该改用热图/分组小图，而不是继续加色。

**禁用配色**：

- ❌ 纯黑 `#000000`（一律 `COLOR_INK` `#333333`）
- ❌ 纯红 `#FF0000` + 纯绿 `#00FF00` 作系列配色（色盲不友好；红绿只按方向色规则出现）
- ❌ `rainbow` / `jet` 色图（感知不均匀）
- ❌ 超过 6 种高饱和色同图
- ❌ 在模板脚本里硬编码十六进制色值（改色请改 `plot_style.py`）

**常见误用 → 修正**：

| 误用 | 修正 |
|---|---|
| 同一方法在各子图里颜色不同 | 一个方法一个颜色，全篇复用 |
| 用红绿区分"方法A/方法B" | 身份用蓝/橙/紫，红绿只标增减 |
| 所有柱等亮等饱和、看不出主次 | 主角全饱和，陪衬走 `TONE_RAMP` |
| 灰色画主结果、亮色画基线 | 反过来：主角取强色，基线取灰 |
| 图例色块占掉三成版面 | 直接标注在线尾/条端，或把图例移到图下方 |

**纹理编码（可选，非默认）**：基础图表不默认加斜线/圆点纹理，靠低饱和配色 + 明度阶梯区分；
确需区分（多组年份等）用透明度或 `HATCH_SEQUENCE`（横线 `---`、竖线 `|||`），
纹理柱体 `edgecolor` 统一白色、`linewidth=0.8`。

## 版式与多子图（Nature 式）

- **坐标框架**：一律调用 `style_axes(ax, grid='y')`——去上/右 spine、0.7pt 细轴线、
  刻度外伸 3.2pt、只保留数值轴方向的浅灰细虚线网格；热图例外（四边需闭合）。
- **字号**：标题 10.5pt 加粗、轴标签 9.5pt、刻度 8.5pt、图例 8.5pt、注释 8pt
  （常量 `FS_TITLE/FS_LABEL/FS_TICK/FS_LEGEND/FS_ANNOT`，勿手写数字）。
- **面板标号**：多子图用粗体小写字母 `add_panel_label(ax, 'a')`，压在轴框外左上；
  每个子图回答一个**唯一**问题，两句话能说清的子图删掉一个。
- **主次版面**：一个主结果需要占主导时用 `width_ratios=[1.5, 1]`（hero + 验证），
  或 `height_ratios=[0.8, 1.5]`（上流程下结果）；hero 面板不得与陪衬面板等大。
- **同指标共享刻度**：子图展示同一指标时 `sharey=True` 或手动统一上下限，避免不同标度误导对比。
- **留白控制**：`save_fig` 已用 `bbox_inches='tight'`；成品空白不宜超过版面 20%。
- **尺寸**：整版宽图 `FIG_FULL`（6.3×4.0in）、双子图竖版 `FIG_TALL`、近方形 `FIG_SQUARE`；
  Nature 单栏宽 89mm≈3.5in，缩到半版心展示时按上文强制要求提高 `font_scale`。

## 高级图表配色要点

- **散点/气泡**：单系列用主角蓝、透明度 0.5–0.6（重叠加深体现密度）；离群/关键解用
  `ACCENT_ORANGE` + 白描边并放大；多系列按 `identity_color(i)` 取色；叠加拟合线用主角蓝加粗。
- **雷达图**：填充主角蓝 α0.2；轮廓主角蓝 2pt 实线；对比模型取次系列身份色虚线填充 α0.1；
  网格用 `NEUTRAL_LIGHT`。
- **桑基图/和弦图**：节点按身份色序列着色；连线半透明 0.4–0.6 且颜色继承起始节点。
- **地图热力图**：底图极简（海岸线/省界浅灰）；数据层用 `SEQUENTIAL_CMAP` 单色顺序系；
  **禁红绿配色**。
- **平行坐标**：降采样 ≤60 条/类；透明度 0.3–0.5；按类别取身份色之一；图例置图外。

## 全局视觉统一（全文图表强制）

- **主色一致**：图 1 用主角蓝代表"模型A"，图 5 中"模型A"必须仍是主角蓝（跨图图例一致）；
- **字体**：西文/数字 Arial（缺则 Helvetica/Liberation Sans，最终兜底 DejaVu Sans），
  中文取黑体系（Microsoft YaHei → SimHei → Noto Sans CJK SC）；未安装的候选由
  `pick_font_stack()` 先过滤，缺中文字体时告警而非静默方框；
- **去噪**：删无意义背景色/过粗边框/阴影；去掉上、右侧轴框线；留白是高级感的来源。

## 基础图型要点（对内置模板的约束说明）

- **折线**：轴标注物理含义+单位；仅保留数值轴浅灰细虚线网格；性能对比坐标轴从 0 起；
  主线主角蓝 2.2pt、次系列 1.5pt 虚线、基准中灰；线型+标记+颜色三重冗余；
  同图曲线 ≤5 条，超限分图；**优先线尾直接标注取代图例**。→ `line-compare`
- **分组柱状**：柱宽统一、组内距 < 组间距；单色扁平无立体；Y 轴从 0 起；
  柱顶数值用 `annotate_bars`（8pt `NEUTRAL_DARK`）；指标取身份色、方案取 `TONE_RAMP` 明度层级；
  对照组相对本文方案的均值增益用 `delta_annotation` 标 `↑/↓`。→ `grouped-bar`
- **条形/排名**：长类别名用横向条形；**按数值降序排列**，第一名主角蓝、逐级走 `TONE_RAMP`；
  条端标注同柱状规范。→ `hbar-longlabel`
- **箱线**：白底箱体 + 身份色边框与同色粗中位线（2.2pt）；均值用白心菱形；
  个体观测以同色半透明抖动点全量呈现；离群点单一中性灰小实心圆。→ `boxplot-jitter`
- **环形图**：≤5 类（过多改柱状）；白色 1.2pt 分隔线；占比由同族明度编码（最大块最深）；
  类别与百分比用引线直接标注在环外，取消图例；性能对比优先柱状/折线。→ `pie-modules`
- **收敛/迭代曲线**：最优线主角蓝加粗、均值线中灰虚线、种群散点用浅调作背景；
  标出收敛代数（竖直虚线）与累计提升（方向色 + `↑/↓`）。→ `convergence-curve`
- **拟合 + 残差**：观测值中性灰、模型线主角蓝、置信带主角蓝 α0.15；
  子图用 `add_panel_label` 标 a/b；`R²`/RMSE/n 以浅灰底文字框直接写在图上。→ `fit-conf-residual`
- **Pareto 前沿**：候选解浅灰点云、非支配前沿主角蓝白心标记；拐点用 `ACCENT_ORANGE` 星标，
  理想点用灰虚线投影到两轴。→ `pareto-front`
- **热力图**：`DIVERGENT_CMAP`（蓝→浅灰→珊红）、`center=0`、白色 0.6pt 格线、
  格内数值用常规无衬线字体（不用等宽）、刻度线归零、必须传入特征名；
  黑白打印变体把 `DIVERGENT_CMAP` 换成 `SEQUENTIAL_CMAP`。→ `heatmap-annotated`

## 渲染自检（交付前必须看产物）

打开渲染出的 PNG/PDF 逐项核对，**代码跑通不等于图没问题**；任一项不过就改代码重渲染：

- [ ] 标题、轴标签、图例、注释、色条没有被裁掉或压线；
- [ ] 没有相互重叠、遮住数值的文字；缩放到论文实际尺寸后仍可读；
- [ ] 单位、排序、上下限、类别标签正确；坐标轴未误导性截断；
- [ ] 没有空子图、没有与另一子图完全重复的信息；
- [ ] 颜色与标记在灰度打印下仍可区分（红绿系列须同时带 `↑/↓` 或正负号）；
- [ ] 主角/基准/不确定度三者指认正确：基准是灰、方向色只出现在有向变化上；
- [ ] 图内数值与数据来源（脚本输出、`frozen_numbers.json`、正文表格）一致，
      不得声称模拟数据复现了某篇文献的真实结果；
- [ ] 图题与图内容说的是同一件事，且没有把相关性写成因果；
- [ ] 产物路径存在并已记入配图计划（三格式 PNG/PDF/SVG）。

论文成稿阶段再按主技能 `math-modeling-helper` 第 7 章自检清单中图表相关项复核。
