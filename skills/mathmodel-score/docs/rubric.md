# 百分制评分细则（唯一权威）

> 本文件是 `mathmodel-score` 技能的规范条文之一，内容提取自原主技能 `mathmodel-core` 的「最终论文评分（百分制）」小节，是**评分口径的唯一权威出处**。自检依据见 [`self-check.md`](self-check.md)（评分细则的扣分项与自检项一一对应）；评分卡由 [`../code/score_card.py`](../code/score_card.py) 计算与校验。

## 评分维度与权重

| 维度 | 分值 | 评分依据 |
| ---- | ---- | -------- |
| **摘要** | 30 | 结构完整性、数值具体性、递进关系、与正文一致性 |
| **算法/模型正确性** | 20 | 数学推导无误、约束完备、求解结果合理 |
| **创新性** | 20 | 方法创新度、跨学科融合、指标构建独创性 |
| **写作能力** | 15 | 逻辑连贯、学术语态、数据支撑、无空泛表达 |
| **排版** | 15 | 格式规范、图表完整、符号一致、编译无误 |
| **合计** | 100 | $S \geq 85$ 方可最终输出 |

维度 id（供 `score_card.py` 与评分卡 JSON 使用）：`abstract`(30) / `model`(20) / `innovation`(20) / `writing`(15) / `layout`(15)。

## 结构门槛（评分前置）

**章节结构 hard 项全部通过方可进入百分制评分**；hard 未过属结构性缺失，先补齐，不计分也不进入优化循环。

```bash
python3 code/check_chapters.py paper/paper.tex --rules cumcm        # 退出码 0 通过 / 1 有未过项 / 2 用法错误
python3 code/check_chapters.py paper/paper.tex --rules mcm --json   # 美赛口径（放宽目录要求、按 25 页限制）
```

- **hard 未过**：按 [`chapter-checklist.md`](chapter-checklist.md) 补齐——如缺符号说明三线表、缺模型评价优缺点、附录缺可运行源程序、正文含目录、出现参赛者身份信息
- **soft 未过**：不阻断评分，按各维度扣分表折算到「摘要 / 写作能力 / 排版」
- **人工项**：摘要三段式、篇幅限制、流程图可读性等由人读判定，判据见 `chapter-checklist.md`
- 身份信息泄露同时触发**一票否决**（`score_card.py` 的 `veto` 字段）

soft 项与扣分维度的对应关系：

| 章节 soft 项 | 扣入维度 |
|---|---|
| 摘要三段式、关键词、每问统一格式、结尾段 | 摘要 |
| 问题重述分点、问题分析代入结论、图表引用与解读 | 写作能力 |
| 符号说明表、假设编号与影响、目录、篇幅、附录与支撑材料列表、AI 使用声明、参考文献格式 | 排版 |

## 与去 AI 模块的分工（以 `mathmodel-deai` 为准）

语言表述类问题**不在本模块定义口径**，一律以 `mathmodel-deai` 为准；本模块只把它的判定结果折算成扣分：

| 本模块的项 | 判定权归谁 | 用法 |
|---|---|---|
| 空泛表达 / 套话 / 模板腔（词表级） | `mathmodel-deai` 的 `check_phrasing.py` | 退出码 1 即命中，按命中处数与 `severity` 折算到「写作能力」 |
| 长句 / 句式重复 / 过渡词 / 段落节奏 / 小数位（结构级） | `mathmodel-deai` 的 `check_style.py` | 退出码 1，或风险等级「高/极高」，不得交付；折算到「写作能力」 |
| 零宽 / 不可见字符 | `mathmodel-deai` 的 `strip_invisible.py` | 交付前 PDF 与 Word 均须退出 0（见 `self-check.md` 致命/严重项） |

两条口径协调（避免本模块的格式要求与去 AI 指标互相误伤）：

1. **编号分点不计入句式与段落统计**：本站要求「假设 X」分点列出、符号说明用三线表，这类同形开头是格式要求而非句式单调；`check_style.py` 已把列表项、编号分点（`假设 X`、`（1）`、`①`、`步骤 X`）与表格行排除在句式重复（M2）与段落节奏（M5）之外。
2. **统一格式 ≠ 段落等长**：摘要逐问段与「问题分析」的统一模板指**信息结构一致**（问题类型 → 模型 → 关键方法 → 结果位置），不是字数齐平；叙事段仍须满足 `check_style.py` 的相邻段落节奏。顺序词只在单一求解流程内部用一组（`首先`…`最后`），问与问之间改用信息量衔接（对应词表 `connector-sequence` 的频次上限）。

## 各维度评分细则

**1. 摘要（30分）**

| 检查项 | 扣分标准 |
| ------ | -------- |
| 模型名称/方法与正文不一致 | 每处 -5 |
| 数值结果与正文表格不一致 | 每处 -5 |
| 缺少具体数值结果（仅定性描述） | -8 |
| 未体现问题间递进关系 | -5 |
| 字数超出 800-1000 字范围 | -3 |
| 缺少误差/不确定度分析 | -4 |
| 开头套话（`随着…的发展` 等）或无实质钩子（矛盾/数字/困境） | -3 |
| 开头段未点明问题背景与核心问题，或超过 3 行 | -2 |
| 关键词非一行，或个数不在 3-5 个 | -2 |
| 每问段未用统一格式（问题类型/所用模型/关键处理方法/结果位置缺项） | 每问 -1 |
| 模型检验写进每问摘要（未单独成段） | -2 |
| 结尾段未讲模型优越性与稳健性，或未落到具体场景 | -3 |

**2. 算法/模型正确性（20分）**

| 检查项 | 扣分标准 |
| ------ | -------- |
| 模型选择无充分理由（未对比替代方案） | -6 |
| 缺少数学模型（无公式结构，纯文字/框图） | -8 |
| 未说明软件名称及理由 | -2 |
| 目标函数或约束条件缺失 | -5 |
| 求解结果明显不合理（如违反物理约束） | -8 |
| 参数设置无依据（未引用文献建议范围） | -3 |
| 题目明确要求的基线/对照缺失 | -5 |
| 解集/最优性论证不足（多目标仅靠人为权重集无全域 Pareto；优化缺最优性间隙或精确法对照） | -3 |
| 算法介绍通用模板化、未结合问题，超参选取逻辑未阐释 | -4 |
| 缺少误差分析/敏感性分析/对比实验 | 每缺一项 -2（若已在摘要维度扣过"缺少误差/不确定度分析"，此处不重复扣） |

**3. 创新性（20分）**

| 检查项 | 扣分标准 |
| ------ | -------- |
| 全部使用基础方法无创新 | -10 |
| 创新点缺乏理论支撑 | -5 |
| 未构建自定义指标或改进算法 | -5 |
| 离题标新立异（创新点与问题无关） | -3 |
| 一味堆砌难度模型（算法与问题规模/约束不适配） | -3 |

**4. 写作能力（15分）**

| 检查项 | 扣分标准 |
| ------ | -------- |
| 存在空泛表达（"较好""显著"等黑名单词） | 每处 -1 |
| 结论缺少数据支撑 | -3 |
| 段落间逻辑断裂 | -2 |
| 病句或表述歧义 | 每处 -1 |
| 无个性化痕迹（方法选型无判断叙述、局限性未点名未量化、展望无具体切入点） | -2 |
| 问题重述的背景部分分点分条（应为纯文本叙述） | -2 |
| 问题分析代入了求解结论或主观判断 | -2 |
| 图表未被正文引用（无「如图/表 X 所示」） | 每处 -1 |
| 图表无文字解读（未给出趋势 + 原因 + 结论） | 每处 -1 |

**5. 排版（15分）**

| 检查项 | 扣分标准 |
| ------ | -------- |
| **出现参赛者身份/学校/赛区信息，或存在页眉（一票否决）** | **直接淘汰，不计分** |
| 页码未从摘要页（第1页）开始，或未页尾居中 | -2 |
| 变量/符号前后不一致 | 每处 -2 |
| 公式编号不连续或重复 | -2 |
| 图表编号跳跃或缺失 | 每处 -1 |
| 图题/表题位置错误（图下表上） | 每处 -1 |
| 非三线表格式（含竖线） | -2 |
| 编译报错或文字超出纸张 | -3 |
| 模型假设未用三线表（用列表/纯文字） | -2 |
| 假设合理性说明空洞（仅写"合理"） | 每处 -1 |
| 假设条数不在4-6条范围 | -1 |
| 正文中未显式引用假设编号 | -2 |
| 跨行公式未居中或右侧缺编号 | 每处 -1 |
| 核心公式缺失或未编号（目标函数/关键约束） | -2（若已在"算法/模型正确性"维度扣过"目标函数或约束条件缺失"，此处不重复扣） |
| 检测量公式重复列出 / 公式过度堆砌 | 每处 -1 |
| Word 中公式为文本/图片模拟，非数学格式 | -2 |
| Word 格式与 PDF 不一致（字体/字号/行距/缩进/标题层级/三线表） | 每处 -1 |
| PDF 无书签，或段末跨页空白较大 | -1 |
| 附录数据与正文矛盾，或正文重要结果附录不可查 | -2 |
| 正文出现目录（国赛格式规范：正文不要目录） | -2 |
| 参考文献未按 GB/T 7714-2015 著录，或正文引用处未标注 | -2 |
| 符号说明未用二列/三列三线表，或列名加粗 | -2 |
| 假设未分点编号（"假设 X"），或未说明该假设造成的影响 | 每处 -1 |
| 附录缺支撑材料文件列表（且未声明"本论文没有支撑材料"） | -2 |
| 附录缺完整可运行源程序（且未声明"本论文没有用到程序"） | -3（国赛格式规范第五条，可能被取消评奖资格） |
| 缺 AI 使用声明（当届规则要求时），或用途描述与支撑材料不一致 | -2 |
| 篇幅超限（国赛正文 >30 页；美赛提交内容 >25 页） | -2 |

## 优化触发规则与熔断

- **$S \geq 85$**：输出最终论文（PDF + Word），附最终评分表
- **$S < 85$**：列出所有扣分项，按分值从高到低排序，逐项修改后重新评分
- **任一维度得分为 0**：不论总分多少，强制优化该维度
- **一票否决**：出现身份信息或页眉等红线，直接淘汰、不计分，不进入优化循环
- **熔断机制**（防止无限循环）：最大优化轮次 **3 轮**；若 3 轮后仍未达标（$S < 85$），输出当前版本论文并附评分表与剩余扣分项说明，明确标注"未达 85 分标准，需人工复核"；每轮优化必须有明确改进动作，禁止无实质性修改的空转

## 竞赛口径对照（国赛 / 美赛）

两赛评阅口径不同，同一篇论文在两边失分点也不一样，评分前先确认目标赛事：

| 维度 | 全国大学生数学建模竞赛（CUMCM） | MCM/ICM 美赛 |
|---|---|---|
| 官方标准 | 以「假设的合理性、建模的创造性、结果的正确性和文字表述的清晰程度」为主要标准 | 不设固定分值表、无量化权重，按论文整体质量评审 |
| 评审方式 | 全国评阅专家组按统一标准评选 | **第一轮只读摘要**，通过后逐轮细读 |
| 摘要地位 | 摘要专用页独立成页，含标题与关键词 | 摘要（Summary）是决定性部分，须写入数值结果 |
| 结构规范 | 格式规范（2026 修订稿）为硬约束：摘要页起编页码、正文 ≤30 页、不要目录、附录须含可运行源程序 | 提交内容（含摘要、目录、注释、附录、代码）≤25 页 |
| 偏好 | 模型正确、结果可信、写作规范、创新点明确 | **问题驱动**而非模型驱动，看重「思考痕迹」可见性与可读性，优点/缺点独立成节 |
| 常见失分 | 套模板、公式堆砌、缺替代方案对比、附录源程序缺失 | 模型黑箱、假设未说明影响、图表缺标注、结论超出结果支持范围、摘要不含结果 |

实践建议：国赛优先保**结构完整 + 附录可复现 + 结论落到题目阈值**；美赛优先保**摘要可独立读懂 + 假设逐条说明影响 + 全文可读性**。

> 口径来源：[全国大学生数学建模竞赛章程（2023 年修订稿）](https://www.mcm.edu.cn/html_cn/block/44e92058f537729c6b6a62a3662ee417.html)、
> [论文格式规范（2026 年修订稿）](https://www.mcm.edu.cn/html_cn/node/4cd596519c9eb9fbd866398f6df0caa3.html)、
> [COMAP 评审维度解读](https://mcmicm.org.cn/news/1175.html)、
> [20 Years of Good Advice（MCM/ICM 评委经验）](https://mcmicm.org.cn/wp-content/uploads/2024/12/1733372418-14.pdf)。

## 评分卡与输出模板

评分卡用 JSON 记录（见 [`../examples/example-scorecard.json`](../examples/example-scorecard.json)）。先跑章节结构门槛，再校验评分卡：

```bash
python3 code/check_chapters.py paper/paper.tex --rules cumcm       # 结构门槛：hard 全过再评分（0 通过 / 1 未过 / 2 错误）
python3 code/score_card.py scorecard.json          # 校验 + 渲染评分表（退出码 0 达标 / 1 需优化 / 2 输入错误）
python3 code/score_card.py scorecard.json --json    # 机器可读输出
python3 code/score_card.py --list-dimensions        # 查看维度契约（含满分）
```

模板：

```
========== 论文评分表 ==========
维度              得分    满分
---------------------------------
摘要              XX      30
算法/模型正确性    XX      20
创新性            XX      20
写作能力          XX      15
排版              XX      15
---------------------------------
总分              XX      100
---------------------------------
判定：[达标/需优化]

扣分明细：
1. [维度] [检查项] -X分：具体说明
2. ...
=================================
```
