# 章节结构自检清单（人读版）

> 本文件是 `mathmodel-score` 的章节级规范，逐条对应《优秀论文自检表》与全国大学生数学建模竞赛论文格式规范
> （2026 年修订稿）。机器可判定项由 [`../code/check_chapters.py`](../code/check_chapters.py) 按数据契约
> [`../code/chapter-checklist.json`](../code/chapter-checklist.json) 执行，**契约是唯一数据源**，本文件与之逐条对应。
>
> - 级别 **hard**：结构性硬项，缺失先补齐再进入评分（不计分）
> - 级别 **soft**：规范性软项，按 [`rubric.md`](rubric.md) 的维度扣分表扣分
> - 方式 **自动** / **人工**：`check_chapters.py` 可判定，或需人读核对
>
> **语言表述类判据**（模板腔、套话、句式重复、段落节奏等）一律以 `mathmodel-deai` 为准，本清单只列结构要求；
> 编号分点（`假设 X`、`（1）`、`①`）不计入去 AI 的句式与段落统计，详见 [`rubric.md`](rubric.md)「与去 AI 模块的分工」。
>
> 命令：`python3 code/check_chapters.py paper/paper.tex [--rules cumcm|mcm] [--strict] [--json]`

## 一、摘要（摘要专用页）

| 部位 | 内容要求 | 级别 | 方式 | 状态 |
|---|---|---|---|---|
| 开头段 | 1-3 行，简要说明问题背景与核心问题 | soft | 人工 | |
| 中间部分 | 每段统一格式、针对问题 X：① 点出问题类型 ② 点出所用模型/方法 ③ 点出该场景下的关键处理方法 ④ 顺序表达、循序渐进、不过多解释；⑤ 给出求解结果，结果较多时标注其位置（附件、表 X） | soft | 人工 | |
| 中间部分 | 模型检验**不写进每问摘要**，单独一段或写在结尾段 | soft | 人工 | |
| 结尾段 | 简述所用模型的优越性与稳健性，说明在具体场景下解决了什么具体问题 | soft | 人工 | |
| 关键词 | 一行，3-5 个，点明场景与核心方法 | hard | 自动 | |

> 摘要页含标题与关键词，原则上不超过一页；论文从此页开始编页码，页脚中部、阿拉伯数字从 1 连续编号。

| 问题背景 | ① 开头用纯背景描述作导入 ② 点明背景下的具体问题 ③ 点明这些问题带来什么困境 ④ 点明解决它们可带来什么价值与意义 ⑤ 这部分**用纯文本表达、不要分点** | soft | 人工 | |

## 六、问题 X 模型建立与求解

| 环节 | 内容要求 | 级别 | 方式 | 状态 |
|---|---|---|---|---|
| 引文 | 一段说明；直接点明该问题的核心方法；直接总述该问题的解题过程 | soft | 人工 | |
| 问题分析 | 点出问题核心、问题类型、问题条件与满足条件的解决方案；点明模型算法与它在该场景下的应用方法；顺序表达、循序渐进、适当加连接词 | soft | 人工 | |
| 准备工作 · 数据处理 | 引文总述流程；简述数据场景并表明处理原因；处理方法与场景适宜；每一步有对应公式与理论支撑；处理前后对比；统计类赛题给必要的统计表与检验分析 | soft | 人工 | |
| 准备工作 · 建模前期准备 | 引文承接上文的处理结果，说明可建立什么类型的模型；表明现有条件与现有场景，说明最适合的模型是什么；说明该模型相较场景或其他模型的优势；引出模型建立 | soft | 人工 | |
| 模型建立（评价类） | 指标的选择过程 → 权重的确定过程 → 评价算法的选择与描述 | hard | 自动 | |
| 模型建立（预测类） | 模型选择与对比 → 模型评估 →（可选）模型解释、特征分析 | hard | 自动 | |
| 模型建立（优化类） | 目标函数建立 → 列出约束条件 s.t. → 选定算法 → 算法核心参数 → 算法核心运行流程 | hard | 自动 | |
| 模型建立（数统类） | 表达场景下的概率分布 →（可选）简化与近似手段 → 表明该分布下的问题类型（概率、期望、估计）→ 该分布下的解决方案（计算、估计、仿真）→ 列出核心公式 | hard | 自动 | |
| 模型建立（机理分析） | 表明问题场景 → 列出核心方程 → 每一步的解析表达式 → 用数学语言表明核心判别过程 → 关键点数值标注 → 每一步的理论依据与名词表述 | hard | 自动 | |
| 模型建立 | 结尾总结，引出模型求解 | soft | 人工 | |
| 模型求解 | 引文引出结果；结果的图、表或明确数值标注；图表清晰、可读性第一；图表在正文中有引用；图表有必要的文字描述与分析；有序数据做可视化或趋势分析；结果较多时给统计分析与结果展示；部分场景给必要的结构示意图 | soft | 自动 + 人工 | |
| 模型检验（评价类） | 准确率与模型解释、特征贡献分析等；灵敏度、鲁棒性；置信区间/假设检验等；部分场景的 Lyapunov 判据、Jacob 矩阵分析等，**检验手段 ≥2 种** | soft | 自动 + 人工 | |
